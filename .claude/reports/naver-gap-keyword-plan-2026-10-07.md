## 1. 결론 먼저

**일 $200은 이번 분기 목표가 될 수 없습니다.** 필요한 트래픽이 현재의 약 2,000~5,000배입니다.
이 계획은 "빈틈 키워드로 그 경로가 실제로 열리는지"를 8주 안에 숫자로 검증하고, 열리면 확장하는 계획입니다.

| 항목 | 값 |
|---|---|
| 목표 | 일 $200 ≈ 일 28만 원 (환율 1,400원 가정) |
| 필요 페이지뷰 | 일 1.9만~5.6만 PV (RPM 15,000~5,000원 가정, 2차 집계라 실측으로 교체 필요) |
| 현재 | 일 약 5~10 PV (GSC 28일 클릭 14 + 기타 유입 추정) |
| 격차 | 약 2,000~5,000배 |

빈틈 키워드 한 개를 네이버 상위로 올려도 월 수십~수백 방문입니다. 일 2만 PV는 빈틈 키워드 수천 개 또는 "X 계산기" 헤드텀(월 수만 검색) 다수에서 상위권이어야 나옵니다.
그래서 **빈틈 키워드는 도착지가 아니라 사다리**입니다. 작은 승리로 네이버의 신뢰(사이트 품질 판단)를 쌓아 헤드텀으로 올라가는 구조입니다.

## 2. 왜 네이버이고, 왜 "계산기" 키워드인가 (실측 근거)

2026-10-07 네이버 통합검색 실측 (외부 도메인은 블로그·지식iN·네이버 서비스 제외):

| 검색어 | 블로그 링크 | 노출된 외부 사이트 |
|---|---|---|
| 청약가점 계산기 | 26 | aptalimi.com · onetoolhub.com · enolasoft.com · apttoyou.kr |
| 양도소득세 계산기 | 31 | tools.devcomma.com · incometax.calculate.co.kr · 부동산계산기.com · 나무위키 · 국세청 |
| 증여세 계산기 | 27 | taxmade · semutong(세무사) · kooltip · sem2em · 홈택스 |
| 퇴직금 계산 | 26 | 국세청 · 노동부 · 사람인 · 잡코리아 · 찾기쉬운생활법령 |
| 자동차세 연납 | 38 | 위택스 · 행안부 · 지자체 · 지역신문 |

해석:
- **"X 계산기" 검색어에는 소형 계산기 사이트가 들어갈 외부 슬롯이 실재한다.** (청약가점·양도세에서 1인 운영 추정 도구 사이트 다수)
- "X 연납", "X 계산"(동사형)처럼 정보형 검색어는 정부·언론이 슬롯을 차지한다. 우리가 이길 자리가 아니다.
- 네이버 2026 랭킹은 "출처 신뢰도 중심 통합 랭킹"으로 바뀌어 외부 웹문서 노출이 늘었다는 업계 보고가 있다 (2차 출처).
- 우리 강점은 **인터랙티브 계산기**다. AI 브리핑이 텍스트로 대체할 수 없는 거래형 의도라 클릭이 남는다.

→ 공략 대상 = **계산 의도가 있는 빈틈 키워드** (예: "2000cc 자동차세 얼마", "증여세 5억 자녀 계산", "퇴직금 3년 근무 계산기"). 정보형 빈틈 키워드는 블로그·정부와 싸우게 되므로 후순위.

## 4. 빈틈 키워드 파인더 (로컬 스크립트, 운영자가 수동 실행)

`scripts/naver-gap-finder.mjs` — 자동 실행 없음. 운영자가 세션에서 돌릴 때만 동작.

### 4-1. 흐름
1. **시드**: 계산기 31종의 핵심어 (연봉 실수령액, 퇴직금, 양도세, 취득세, 증여세, 자동차세, 청약가점 …)
2. **확장**: 검색광고 API로 시드당 연관어 수집 → 월간 검색량 부착
3. **필터**
   - 월간 검색량 ≥ 200 (초기값, 실측 후 조정)
   - **계산 의도**: 계산/계산기/얼마/세금/공제/실수령/환급 등 포함 또는 금액·cc·년수 같은 수치 포함
   - 대출·보험·투자 권유성 키워드 제외 (YMYL·금소법 리스크)
   - 기존 페이지(계산기 31 + 가이드 383)와 중복 제거
4. **경쟁도**: API HUB로 블로그·웹문서 `total`
5. **빈틈 점수** = 월간 검색량 ÷ 블로그 문서 수 (+ 웹문서 상위에 소형 도구 사이트가 있으면 가점, 정부·언론만 있으면 감점)
6. **출력**: `.claude/reports/naver-gap-YYYY-MM-DD.md` 순위표 (키워드 · 검색량 · 문서수 · 점수 · 대응 계산기 · 권장 처리)

### 4-2. "권장 처리" 3가지
| 처리 | 언제 | 예 |
|---|---|---|
| **기존 계산기 보강** (1순위) | 키워드가 기존 계산기 사용 사례 | "2000cc 자동차세" → 자동차세 계산기에 배기량별 결과표·프리셋 |
| **기존 가이드 보강** | 관련 가이드가 이미 있음 | 해당 H2·표 추가 |
| **신규 페이지** | 맞는 페이지가 없고 수요 근거 충분 | 운영자 검수 후 수동 발행 |

신규 페이지보다 **기존 계산기 보강을 우선**한다. 371편 가이드 중 36%가 노출 0이었던 교훈: 페이지 수는 수익 함수에서 이미 빠진 항이다.

## 5. 실행 단계

### 0단계 (1주차): 계정·키 준비 — 운영자
| 할 일 | 소요 |
|---|---|
| 네이버 서치어드바이저 소유확인 (HTML 파일 방식 → 파일명·내용을 알려주시면 제가 배포) | 15분 |
| 서치어드바이저에 sitemap.xml · feed.xml 제출 | 5분 |
| 네이버 클라우드 콘솔 > NAVER API HUB > Application 등록 → Client ID/Secret | 15분 |
| searchad.naver.com 가입 → 도구 > API 사용관리 → CUSTOMER_ID · API_KEY · SECRET_KEY | 20분 |
| 위 키를 `.env.local` 에 직접 입력 (채팅에 붙여넣지 말 것) | 5분 |
| AdSense 90일 광고 노출수 확인 (게재 문제인지 판정) | 5분 |

`.env.local` 에 넣을 이름:
```
NAVER_APIHUB_CLIENT_ID=
NAVER_APIHUB_CLIENT_SECRET=
NAVER_SEARCHAD_CUSTOMER_ID=
NAVER_SEARCHAD_API_KEY=
NAVER_SEARCHAD_SECRET_KEY=
```

### 1단계 (1~2주차): 파인더 구축 — Claude
- `scripts/naver-gap-finder.mjs` + 서명(HMAC-SHA256)·`total` 파싱 순수 함수 단위 테스트 (TDD)
- 첫 실행: 시드 31개 → 후보 수백 개 → 상위 30개 선정
- `.env.example` 에 키 이름만 추가 (값 없음)

### 2단계 (3~8주차): 주 3편 수동 공략 — 운영자 + Claude
- 운영자가 세션을 켜면 Claude가 파인더 상위 키워드 1개로 초안 작성 → **운영자 검수** → push
- 한 편 = 빈틈 키워드 1개 + 대응 계산기로 직접 이어지는 구조 (계산 결과표, 경계값 예시, §N 1차출처 확인)
- 하네스 `.claude/rules/new-post-seo-geo-harness.md` §1.5·§2 그대로 적용 (네이버 5축 포함)
- 6주 × 3편 = 약 18건 (보강 포함)

### 3단계 (9주차~): 측정 → 확장 또는 전환
- 서치어드바이저 "콘텐츠 노출 및 클릭" 주간 기록 + GA4 네이버 유입
- 이긴 키워드 패턴(계산기·수치 유형)을 파인더 가중치에 반영해 다음 30개 선정

## 7. 지킬 것 (어기면 계정이 날아감)

- **자동 발행 금지**: 파인더는 키워드만 찾는다. 글은 운영자 세션에서 검수 후 발행.
- **템플릿 대량 생성 금지**: 네이버 2026-07 스팸 기준 "동일·유사 템플릿 저품질 대량 생성(AI 포함)". "2000cc / 2500cc / 3000cc 자동차세" 같은 키워드를 페이지 수십 개로 찍어내지 말고, **한 계산기 페이지 안의 결과표**로 흡수한다.
- **YMYL**: 세율·§N은 law.go.kr·국세청 1차출처 확인 후만. 확인 못 하면 쓰지 않는다.
- **AdSense 정책**: 사람 검수 없는 자동 생성 콘텐츠에 광고 금지 조항. 검수 기록을 면책 문구에 남긴다.
- **네이버 SERP 스크래핑 금지**: 순위·슬롯 확인은 API HUB 결과와 서치어드바이저 리포트로만.
- **API 키는 `.env.local` 에만**. 코드·커밋·채팅 금지 (CLAUDE.md 시크릿 규칙).

## 8. 정직한 한계

- RPM 5,000~15,000원은 2차 집계다. 실제 값은 이 계정 데이터로만 알 수 있다.
- 빈틈 키워드의 검색량은 대부분 월 수백 회라, 한 개를 이겨도 월 수십 방문이다.
- 네이버 외부 슬롯은 페이지당 몇 개뿐이고 블로그(검색어당 26~38개 링크)가 압도적이다.
- 사이트가 네이버 신뢰를 아직 못 받았다(서치어드바이저 미등록, 백링크 0). 0단계 없이는 시작할 수 없다.
- 일 $200은 이 사이트가 국내 상위권 계산기 사이트가 되어야 가능한 숫자다. 6~12개월 게이트에서 경로가 안 보이면 목표를 바꿔야 한다.
