### 1-3. 감사 스크립트 4종이 대량 오탐 → 진짜 회귀를 은폐

#### (a) `scripts/ralph-meta-audit.mjs` — 286/286 전부 fail (Pass 0)

**버그 1: canonical 정규식이 문자열 리터럴만 인식**
```js
// scripts/ralph-meta-audit.mjs:48
const canonicalMatch = content.match(/canonical:\s*['"]([^'"]+)['"]/);
```
실제 코드는 변수 참조:
```tsx
// src/app/calculator/acquisition-tax/page.tsx:25,41
const URL = 'https://calculatorhost.com/calculator/acquisition-tax/';
alternates: { canonical: URL },   // ← 리터럴이 아니라 변수
```
→ 계산기·가이드 전 페이지 "canonical URL missing" **오탐**. 실제로는 전부 정상.

**버그 2: JSON-LD 이름 불일치**
```
요구 'BreadcrumbList'  ← 매칭 실패 →  탐지 'buildBreadcrumbJsonLd'  (List 없음)
요구 'FAQPage'         ← 매칭 실패 →  탐지 'buildFaqPageJsonLd'     (대소문자 다름)
```
→ 계산기 전 페이지 "missing required JSON-LD" **오탐**. 실제로는 6종 모두 생성됨.

## 5. 💰 수익화 영향 평가

- **영향 페이지**: all (371 라우트)
- **수익 항**:
  - `indexing` — sitemap·canonical·색인 표면은 **현재 정상**. 위험은 "회귀를 감지 못하는 상태" 자체.
  - `traffic` — description 미달 9개(고CPC 상속·증여·재산세 클러스터) + llms.txt 미활용이 직접 손실.
  - `rpm` — 슬롯 ID 중복으로 배치 최적화 근거 데이터 손실.
- **GSC 사정권 키워드 비교 권고**: description < 80자인 상속·증여 가이드 9편은 메타에 40자 이상 여백 → GSC 8~20위 쿼리 의도 흡수 여지 큼.
- **부작용 검토**:
  - 메타 변경이 기존 1~7위 쿼리 CTR 저하 위험: **낮음** (현 description은 SERP 잘림 한계 미만 = 정보량 부족, 추가는 순증)
  - canonical 변경 위험: **없음** (변경 대상 아님 — 스크립트만 수정)
  - 게이트 면제 목록 도입 시 YMYL 검증 약화 위험: **면제를 비-YMYL 경로로 한정**하면 회피 가능
