## 5. 💰 수익화 영향 평가

- **영향 페이지**: all (286 라우트)
- **수익 항**:
  - `indexing` — sitemap·canonical·색인 표면은 **현재 정상**. 위험은 "회귀를 감지 못하는 상태" 자체.
  - `traffic` — description 미달 9개(고CPC 상속·증여·재산세 클러스터) + llms.txt 미활용이 직접적 손실.
  - `rpm` — 슬롯 ID 중복으로 배치 최적화 근거 데이터 손실.
- **GSC 사정권 키워드 비교 권고**: description < 80자인 상속·증여 가이드 9편은 GSC 8~20위 쿼리를 메타에 담을 여백이 40자 이상 남아 있음 → 의도 흡수 여지 큼.
- **부작용 검토**:
  - 메타 변경이 기존 1~7위 쿼리 CTR 저하 위험: **낮음** (현재 짧은 description은 SERP 잘림 이하 = 정보량 부족 상태, 추가는 순증)
  - canonical 변경 위험: **없음** (변경 대상 아님 — 스크립트만 수정)
  - 게이트 면제 목록 도입 시 YMYL 검증 약화 위험: **면제를 비-YMYL 경로로 한정**하면 회피 가능
- **revenue-lever 권장 태그**: 1~6·11번 = `guard` / 7·9·10번 = `traffic`+`indexing` / 8번 = `rpm`
