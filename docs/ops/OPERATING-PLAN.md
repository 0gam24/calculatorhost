> → 목표는 **하루 100달러** 하나. 판단 기준은 "네이버 검색 유입을 늘려 광고 수익으로 이어지는가". 콘텐츠뿐 아니라 구조·UI·아키텍처 변경도 범위 안.
> 이 문서는 세션이 바뀌어도 같은 방향으로 이어 가기 위한 운영 기준이다. 매 세션 시작 시 `.claude/STATE.md` 다음으로 읽는다.

## 1. 목표까지의 거리 (정직한 산수)

- 하루 100달러 = 하루 PV 약 16,700 (RPM 5달러 가정, 방문당 1.2 PV). 2026-09 기준 월 PV 60~300.
- 2026-10-08 첫 네이버 실측: 대표 검색어 35개 모두 자사 웹문서 30위 밖. 상위는 제목이 검색어와 글자 그대로 같은 소형 계산기 사이트가 차지(예: "부가세 계산기" 상위 10개 대부분 제목이 "부가세 계산기"로 시작, 우리는 "부가가치세 계산기").
- 계산기 대표 검색어 하나가 네이버 1~2위에 들면 하루 1~10달러 (데이터랩 1점 ≈ 주 50명, awoo 실측 계수).
  주휴수당 계산기(평균 68) ≈ 하루 3달러, 퇴직금 계산기(245) ≈ 하루 11달러, 환율 계산기(1,330) ≈ 하루 57달러(네이버 자체 위젯 때문에 어렵다).
- 그래서 길은 하나다. **수요가 큰 "X 계산기" 대표 검색어를 하나씩 상위에 올린다.** 롱테일 가이드는 형태마다 수요가 1/10~1/50이라 편수로는 못 메운다(2026-09 진단: 성숙 가이드 편당 월 0.02~0.03클릭).

## 2. 우선순위 (높은 것부터)

1. **막힌 채널 풀기 (운영자만 가능)**
   - NAVER API HUB 키 또는 기존 개발자센터 앱에 "검색" API 추가 → 검색 결과 정찰이 돼야 빈틈을 고를 수 있다.
   - 네이버 서치어드바이저 소유확인 → 사이트맵 제출·수집 요청·노출 리포트. 한국 유입의 62.9%가 네이버인데 3개월간 채널이 꺼져 있었다.
2. **시기 선점** (`docs/ops/landgrab-calendar.json`, writeBy 순서). 피크 1~2개월 전에 계산기·대표 글을 갱신한다.
3. **없는 계산기 만들기** (수요 큰 순). 계산기는 AI 요약이 대체하지 못하고, 네이버 위젯이 없는 주제면 웹문서 상단을 노릴 수 있다.

   | 주휴수당 계산기 | 평균 68, 1월 피크 88 | 2026-10-07 착수 |
   | 연차수당 계산기 | 평균 17, 1월 피크 32 | 12/1 전 |

4. **이미 있는 계산기 보강** (목록의 "계산기 보강" 항목). 정찰 결과 자리가 열린 순서로. 제목·메타는 바꾸지 않는다(CTR 동결).
5. **정책 위생** (가드): 무검수 15편 사실 대조·수정, 오인용 조항 정정. 수익보다 앞서는 제약이다.
