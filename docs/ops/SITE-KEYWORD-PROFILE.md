## awoo와 결정적으로 다른 점 3가지

1. **우리는 도구다.** 이식 지침서는 "도구(계산기)가 점령한 검색 결과는 글로 못 이긴다"를 함정으로 꼽는다. awoo에겐 피할 자리지만 **calculatorhost에겐 정면 승부처**다. 2026-10-07 실측에서 "청약가점 계산기"·"양도소득세 계산기" 네이버 결과에 소형 계산기 사이트(aptalimi·onetoolhub·devcomma·부동산계산기.com)가 실제로 노출됐다. 호스트 분류표에서 "도구"는 우리에게 **뺏을 수 있는 자리(경쟁자)**로 센다.
2. **자동화가 없다.** 지침서 6단계(GitHub Actions 레이더 하루 2회·순위 매일·파이프라인 매일)는 적용하지 않는다. GitHub Actions 10개는 전부 꺼져 있다(2026-09-30). 데이터 갱신은 **운영자가 세션에서 대시보드나 "목록"을 열 때만** API를 호출해 로컬에서 다시 뽑는다. 봇 커밋 없음.
3. **수익 배수 근거가 없다.** awoo는 애드센스 페이지별 보고서로 주제 배수(0.4~2.0)를 맞췄다. calculatorhost는 3개월 수익 0이라 근거가 없다. 처음엔 전 주제 1.0(중립)으로 두고, 애드센스 페이지별 자료가 생기면 맞춘다.

## 2. 트랙 3개 (calculatorhost 버전)

### T1 물결 버스트: "기준 변경·고지 사건 × 계산 대상"
- **사건**: 세율·요율·기준금액이 바뀌어 시행되거나, 고지서·납부가 몰리는 시점.
  예) 최저임금 고시(8월)·시행(1/1) · 국민연금 요율 인상(7월) · 세법 개정 시행(1/1) · 재산세 고지(7·9월) · 종부세 고지(11월 말) · 자동차세 연납(1월)
- **분해 단위**: 계산 대상. 금액 구간(연봉·과세표준) · 배기량 · 근속연수 · 주택 수 · 공시가격 구간
- **창**: 시행·고지 D-7 ~ D+10 (awoo의 D-7~D+8보다 고지서 확인 기간만큼 길게)
- 예) "2027 최저임금 주휴수당 계산" (8월 고시 직후) · "재산세 고지서 공시가격 3억 얼마" (7월)

### T2 대형 세부 롱테일: 큰 키워드 × 세부 의도
- 수치형: "연봉 4500 실수령액" · "퇴직금 3년 근무" · "2000cc 자동차세"
- 조건형: "퇴직금 1년 미만" · "1세대1주택 12억 초과 양도세"
- 계산법형: "주휴수당 계산법 주 15시간" · "누진공제 계산"
- 비교형: "원리금균등 원금균등 차이" · "분리과세 종합과세 비교"
- 오류형: "퇴직금 계산이 회사랑 다를 때"
- **수치형은 페이지를 늘리지 않는다.** 네이버 2026-07 스팸 기준(동일·유사 템플릿 대량 생성) 때문에, 수치 변형은 해당 계산기 페이지 안의 **결과표 행**으로 흡수한다.
