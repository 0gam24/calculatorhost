# 015. 2026년 보험료·공제·자녀장려금 계산 교정

상태: 미리보기 구현, 운영 반영 보류. 날짜: 2026-09-30.

연봉 계산기는 2025년 보험료를 2026년 값으로 표시했고, FAQ·정적 예시표가 실제 산식과 서로 달랐다. 공유 자녀세액공제 상수와 자녀장려금의 소득 기준도 공식 법령과 달랐다. 독자에게 잘못된 금액을 제시하면 계산기 신뢰와 검색 유입 자산을 해치므로, 공식 자료를 확인한 값과 적용 시점을 상수에 모으고 예시표를 같은 순수 함수로 생성한다.

- 국민연금 근로자 4.75%, 건강보험 3.595%, 장기요양은 건강보험료의 13.14%를 적용한다. 국민연금은 적용월과 천 원 미만 절사를 반영한다.
- 비과세 제외 총급여로 근로소득공제를 계산한다. 자녀세액공제는 적격 1명 25만 원, 2명 55만 원, 셋째부터 각 40만 원 추가다.
- 급여 소득세는 간이세액표 직접 조회가 아닌 연간 누진세의 월 환산 근사다. 누락된 실제 공제와 원천징수 선택, 보험료 신고기준·상하한을 공개한다. 국세청 급여명세서와 일치한다고 주장하지 않는다.
- 자녀장려금은 자격 총소득과 지급 총급여액등을 분리한다. 총소득 7,000만 원 미만, 재산 2.4억 원 미만, 홑벌이 2,100만·맞벌이 2,500만부터 100만→50만 원 감액, 재산 1.7억 원 이상 50% 감액을 반영한다. 실제 국세청 산정표, 중복 자녀세액공제, 기한후·체납은 미반영임을 표시한다.
- 별도 DTI 계산은 모든 주택담보대출 원리금과 기타 부채 이자를 합산한 비율만 제공하며 승인 여부를 판정하지 않는다.
