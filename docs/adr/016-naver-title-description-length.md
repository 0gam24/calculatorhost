# ADR-016: 제목 40자·설명 40~80자, 실측 검색어를 제목 맨 앞에 (네이버 기준 통일)

- 상태: 채택 (2026-10-08)
- 결정자: 운영자 위임 하의 Claude ("목적은 딱 하나 1일 100달러, 모든 걸 네이버 상위 노출로", 2026-10-08)

## 배경

- 첫 네이버 실측(NAVER API HUB webkr, 2026-10-08): 대표 검색어 35개 모두 자사 웹문서 30위 밖.
- "부가세 계산기" 상위 10개는 대부분 제목이 검색어와 글자 그대로 같은 형태로 시작한다. 우리 제목은 "부가가치세 계산기 2026 | 일반·간이·환산 | calculatorhost"(42자)였다.
- 네이버 공식 가이드 `docs/references/H-네이버-공식가이드/06-웹사이트 검증/01-사이트 간단 체크.md` 는 제목 40자, 설명 80자 이내를 권장한다. 계산기 32개 중 다수가 둘 다 넘었다.
- 기존 규칙(설명 80~155자)은 구글 기준이었다. 그 규칙 문서도 "한글 80자 ≈ 구글 SERP 잘림 한계"라고 적고 있었다.

## 결정

1. 제목은 40자 이내로 쓴다. 데이터랩으로 실측한 검색어 형태를 맨 앞에 둔다(예: "부가세 계산기", "디데이 계산기", "예금이자 계산기", "종부세 계산기"). 브랜드명은 붙이지 않는다.
2. 메타 설명은 40~80자, 1~2문장으로 쓴다. 첫 문장에 결론을 둔다.
3. 2026-10-08 계산기 32개를 한 번에 정규화했다. 그 뒤로는 **한 분기 동안 제목을 다시 바꾸지 않는다.** 네이버 콘텐츠 가이드는 검색 노출만을 위해 제목을 자주 바꾸는 것을 어뷰징 신호로 본다. 사실 오류 정정은 예외다.
4. E2E `tests/e2e/seo-regression.e2e.ts`, `.claude/rules/seo-content.md`, `calculators.md`, `new-post-seo-geo-harness.md` §4-1 을 이 기준으로 바꿨다.
5. 2026 9월 동결 목록의 "제목·메타 리라이트 금지"는 구글 CTR 근거였다. 네이버 실측 검색어에 맞추는 변경은 이 ADR 로 허용한다.

## 결과 확인

- 소유확인 뒤 서치어드바이저 노출·클릭 리포트로 4주 뒤 비교한다.
- 그 전에는 `node scripts/keyword-pipeline.mjs --serp` 로 대표 검색어의 자사 webkr 순위를 잰다(기준: 2026-10-08 전부 30위 밖).
- 구글: GSC 28일 창. 기준선은 클릭 14, 노출 3,125(2026-08-31~09-28)이다. 제목이 바뀐 페이지의 노출이 크게 줄면 그 페이지만 되돌린다.

## 같이 정정한 사실 오류

- 상속세 설명에 상속공제로 잘못 들어 있던 "자녀장려금"을 뺐다.
- 부가세 설명에 남아 있던 7월 확정신고 시점 문구를 뺐다.
- BMI·D-day 등의 "2026년 최신 세율 반영" 상투구를 뺐다.
