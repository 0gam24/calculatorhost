# 검색 안내 후속 교정 — 로컬 검토본

기준 운영 커밋은 `f4bfe2040a8b1840d18b76c67eb0ddee25f155b4`, 작업 브랜치는 `codex/search-answer-followup-2026`이다. 이번 단계에서 원격 push·운영 배포·계정 접근·광고 변경은 하지 않았다. 미배포 API와 홈 정보 커밋은 포함하지 않았다.

## 실제 확인한 문제와 변경

현재 소스와 공개 운영 HTTP 세 페이지를 직접 비교했다. 모두 HTTP 200, self canonical, H1 하나이며 이전 검색 의도·계산 연결 개선이 실제 적용된 상태였다. 기존 추출 캐시를 진단 근거로 사용하지 않았다.

- 물가 계산기: 기존 제목·메타·첫 설명·계산식을 유지했다. FAQ의 2024년 2.4%와 본문의 2.3% 충돌을 공식 연간 CPI 2.3%로 정리하고 발표일·원문을 연결했다. 근거 없는 2026년 전망·평균·품목별 범위·권장 상승률은 제거했다. 한국은행 목표 2%와 미래 전망을 구분하며 입력률은 사용자가 정한 가정이라고 설명한다. 투자수익 차감은 근사와 정확한 비율 계산을 구분하며 이 도구가 투자수익을 계산하지 않는다고 밝혔다.
- 프리랜서 비교: ‘일반직’을 ‘직장인’으로 제목·OG·구조화 데이터·H1·표·경로 표시에 통일했다. 첫 답변은 매출과 연봉을 바로 비교할 수 없으며 같은 기간의 비용·최종 세금·보험료를 반영해야 한다고 설명한다. 기존 급여·프리랜서 계산기 링크, FAQ와 급여 예시 수치는 보존했다.
- 세금·부동산 허브: 제목·설명에 매수 취득세→보유 재산세·종부세→매도 양도세 목적을 반영했다. 기존 세 계산기 링크 아래 실제 입력에 맞춘 준비 조건을 한 줄씩 추가했다. 입력값 자동 전달은 없다. 다른 네 허브 정의와 모든 허브의 기존 글 목록·ItemList를 보존했다.

수정 소스는 네 파일과 세 URL의 수정일 manifest다. 계산 함수·상수·입력 기본값·API·데이터·분석 함수·광고·의존성·workflow·URL을 변경하지 않았다. 수익 목적은 기존 노출 페이지의 내용 이해와 계산기 이용을 돕는 것이며 검색 순위·CTR·수익 상승은 아직 가설이다.

## 검사 결과와 한계

- 단위 테스트 68파일/1,284개, typecheck, lint 통과.
- 실제 `npm run build`의 prebuild/build/postbuild 통과, 정적 페이지 503개. 검사 중 외부 요청과 비공개 `.my` 읽기 시도 모두 0건.
- Chrome 격리 프로필 로컬 산출물 검사 28/28 통과: 모바일 390px·데스크톱 1440px, 기존 다섯 연결/뒤로가기/48px 링크, JavaScript 없는 링크, 물가 세 모드의 독립 기대값, 고정 slug 이벤트 payload와 localhost 측정 억제. 모든 요청은 로컬 out에서 제공하고 외부 광고·분석을 차단했다. 실제 GA4 수신 검사가 아니다.
- 435개 URL·self canonical·색인 허용·H1·JSON-LD 확인. 변경 세 페이지 외 메타/JSON-LD/H1와 모든 허브의 ItemList가 이전 최종 빌드와 동일하다. lastmod는 세 URL만 실제 교정 시각으로 갱신했다. 물가·프리랜서 FAQ와 JSON-LD는 보이는 질문·답변과 일치한다.
- 공개 HTML 444개의 본문·메타·접근성 속성·JSON-LD에서 AI 관련 방문자 문구 0건.
- 최초 export 검사에서는 Next.js 직렬화 스크립트의 중복 텍스트도 세어 준비 안내를 여섯 줄로 오인했다. 검사에서 script/style/noscript를 제외한 뒤 소스 수정 없이 최종 대조를 통과했다.
- 자동발행용 `check-guide-quality`는 RED다. 이전 버전도 AI 보조 표기와 내부 revenue-lever 태그 누락으로 RED였다. 공개 AI 문구를 제거하라는 사용자 지시를 유지했으며 검사를 통과로 보고하지 않는다. 새 OG alt 경고는 `alt: TITLE` 상수를 인식하지 못하는 리터럴 정규식의 오탐이다. 실제 HTML의 `og:image:alt` 값은 존재하고 정확하다. 이 검사나 workflow를 수정·재활성화하지 않았다.

증거는 저장소 밖 `../preview-evidence/search-answer-*`에 보존했다. 온라인 Rich Results Test, 실제 스크린리더, field CWV, 검색엔진 재색인·스니펫, 현재 분석·수익 수신과 사이트 전체 법령 정확성은 검증하지 않았다. 기존 API 404와 법령 레지스트리 잔여가 해결됐다고 주장하지 않는다.

## 측정 계획과 필요한 계정 확인

GSC 원본 저장본은 원본 폴더 `.claude/reports/gsc-latest.json`, 수집 2026-09-30, 기간 2026-08-31~09-28 포함 29일이다. 물가 626노출/1클릭/CTR0.1597%/평균8.0016, 세금 허브127/1/0.7874%/6.5984, 프리랜서 비교64/3/4.6875%/8.7188이다. 모두 개편 전 자료이며 이번 교정의 효과가 아니다. 검색어 집계는 별도로 읽었다. ‘프리랜서 세후계산기’ 3노출과 물가 표현 각1노출 등을 특정 페이지에 귀속하지 않았다.

향후 배포하면 배포일을 기록하고 같은 페이지·기기·국가·기간 조건으로 노출·클릭·CTR·평균순위를 비교한다. 첫 주 신호와 28일 비교를 구분하고 검색어 구성·작은 표본·계절성을 함께 본다. 기존 `guide_calculator_open`의 고정 source/target별 이동과 `calculator_complete`를 별도로 확인한다. 두 집계만으로 가이드별 완료율이나 고유 사용자 전환을 단정하지 않는다. 금융 입력값이나 검색 문자를 측정에 추가하지 않는다.

현재 계정 접근 없이 확인한 것은 저장본과 코드·합성 브라우저 payload다. 최신 GSC 페이지별/검색어별 보고서, Naver 색인 상태, GA4 이벤트 실제 수신·측정기준 설정, 해당 페이지군의 방문당 수익 보고가 필요하다. 새 계정·키·권한을 만들거나 색인 요청을 전송하지 않았다. 운영 반영 여부는 이 실제 변경범위와 잔여 검사 한계를 검토한 뒤 결정한다.
