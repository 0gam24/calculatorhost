# 계산 로직 조사·수정 범위

원본 개발 폴더를 수정하지 않고 `codex/premium-calculators-2026` 미리보기 체크아웃에서 작업했다. 모든 변경은 운영 배포 보류 상태다.

31개 경로의 client component → 순수 계산 모듈 → 단위테스트 파일 연결을 [구조 조사 JSON](calculator-formula-coverage-2026-09-30.json)에 기록했다. 현재 31개 모두 독립 계산 함수와 관련 테스트 연결을 찾았다. DTI는 이전 페이지가 대출한도 도구로 이어지는 설명 페이지여서 별도 비율 함수와 9개 테스트를 추가했다. 연결 조사는 정적 import 검사이며 각 법률 요건의 정확성 또는 입력 검증 완전성을 증명하지 않는다.

실제 실행한 마지막 계산 회귀 확인은 `node node_modules/vitest/vitest.mjs run tests/unit/finance tests/unit/tax --reporter=dot`이다. 29개 파일 732개 테스트가 통과했다. 새 급여 53개, 자녀장려금 18개, DTI 9개 테스트를 포함한다. 기존 기대값에 과거 보험료·공제가 남아 있던 프리랜서 및 교차검증 테스트는 공식 2026년 기준으로 수정했다. 이 결과를 기존 문서의 `392 tests`·`953 PASS` 등 다른 시점의 숫자와 혼용하면 안 된다.

주요 수정과 공식 근거는 [ADR015](../adr/015-2026-social-insurance-and-benefit-corrections.md)에 정리했다. [NPS 연금보험료 안내](https://www.nps.or.kr/pnsinfo/ntpsklg/getOHAF0038M0.do?menuId=MN24001113)를 직접 열어 2026년 총 9.5%, 근로자 4.75%, 2025-07-01~2026-06-30의 40만~637만, 2026-07-01~2027-06-30의 41만~659만과 기준소득 천 원 미만 절사를 확인했다. 상반기와 하반기 기준 모두 공단 원문에서 독립 검증했다.

남은 정확성 제한:

- 급여는 실제 간이세액표 조회가 아니다. 사회보험료 소득공제·근로소득세액공제·특별공제 및 80/100/120% 원천징수 선택 미반영. 실제 공식 급여 계산기와 전액 일치 교차검증은 미완료다.
- 보험료는 공단 신고소득, 가입조건·정산·다중사업장과 건강보험 상하한을 모두 구현하지 않는다. 일반 월급의 요율 추정으로 표시한다.
- 자녀장려금은 연속산식이며 국세청 산정표의 구간 금액과 자녀세액공제 중복조정·기한후 신청·체납을 구현하지 않는다. 실제 지급액이라는 확정 표현을 제거했다.
- DTI 비율은 총 주담대 원리금 + 기타 부채 이자다. 금융기관의 심사 소득·상환액 정의와 LTV/DSR 규제 적격성을 판정하지 않는다.
- 이번에 공식 산식까지 자세히 교정한 범위는 급여, 공유 자녀공제(프리랜서), 공유 건강보험(N잡), 자녀장려금, DTI다. 나머지 계산기의 모든 2026년 법 개정·특례를 새로 검증하지 않았다.
- `.agents` 세율 참고 및 `.claude/VERIFICATION_CHECKLIST.md`에는 과거 요율과 잘못된 예시가 있다. 공식 출처와 현재 코드 상수를 우선하며 해당 문서를 법률 SSoT로 간주할 수 없다.

초기 Vitest는 esbuild 상위 경로 조회가 샌드박스에 막혀 시작하지 못했다. 동일 격리 체크아웃에서 승인된 확장 실행으로 실제 테스트를 수행했다. TypeScript 확인은 다른 에이전트가 파일을 작성 중인 시점에 여러 공유 UI·테스트 오류를 보고했으며 최종 통합 검증은 별도 테스트 담당이 실행해야 한다. 브라우저 세션이나 계정은 사용하지 않았고 웹 도구로 공식 문서만 열었다.
