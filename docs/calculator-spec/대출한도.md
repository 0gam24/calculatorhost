- **카테고리**: 금융 / 부동산
- **타깃 페르소나**: B (대출 실행 예정자), A (부동산 거래 직전자)

- **2차 키워드**: LTV 계산기, DTI 계산기, 주담대 한도, 스트레스 DSR
- **우선순위**: MVP #4
- **CPC 티어**: ★★★★★ ($30-47)

## 2. 사용자 가치
"연소득·기존대출·담보가치를 입력해 신규 주담대로 받을 수 있는 최대 한도를 DSR·LTV·DTI 세 가지 규제 기준으로 즉시 확인"

## 3. 배경: 규제 (2026-10-14 기준, ADR-017)

### 3-1. DSR (Debt Service Ratio, 총부채원리금상환비율)
```
DSR = (모든 대출의 연간 원리금 상환액) / 연소득 × 100
```
- 전 금융권 합산. 은행 40%, 2금융권 50% (8·13 대책 유지)
- **스트레스 DSR** (한도 계산에만 쓰는 가산 금리, 실제 이자는 약정금리):
  - 수도권·규제지역 주담대: 3.0%p (2025-10-16~). 30년 만기 기준 변동형 100%, 혼합형(5년 고정) 80%, 주기형(5년) 40%, 고정형 0 → 3.0 / 2.4 / 1.2 / 0%p
  - 지방 주담대: 1.5% × 50% = 0.75%p (2단계, 2026-12-31까지). 변동 100%, 혼합 60%, 주기 30% → 0.75 / 0.45 / 0.225 / 0%p
- 1주택자 전세대출 이자는 수도권·규제지역에서 2025-10-29부터 DSR 반영

### 3-2. LTV (Loan To Value, 담보인정비율) 와 주담대 최대한도
```
LTV = 주담대 / 담보가치 × 100
```
- 무주택·처분조건부 1주택: 규제지역 40%, 그 밖의 수도권·지방 70%
- 생애최초: 수도권·규제지역 70%, 지방 80% (대출 최대 6억 원)
- 수도권·규제지역 2주택 이상: 주택구입 주담대 불가 (계산기는 입력 대상에서 제외하고 안내)
- 주택구입 주담대 최대한도 (수도권 전체 + 규제지역): 시가 15억 원 이하 6억, 15억 원 초과 25억 원 이하 4억, 25억 원 초과 2억
- 수도권·규제지역 만기 최장 30년, 6개월 안 전입
- 규제지역 (투기과열지구이자 조정대상지역): 서울 25개 구 전체, 경기 과천·광명·성남 분당·수정·중원·수원 영통·장안·팔달·안양 동안·용인 수지·의왕·하남, 2026-07-01부터 화성 동탄구·용인 기흥구·구리시

### 3-3. DTI (Debt To Income, 총부채상환비율)
```
DTI = (신규 주담대 연 원리금 + 기존 기타대출 연 이자) / 연소득 × 100
```
- 규제지역 40%, 그 밖의 지역 60% (대부분 DSR이 먼저 한도를 정함)

## 4. 입력 파라미터

| 필드 | 타입 | 옵션 |
|---|---|---|
| 연소득 | number + 단위버튼 | 원 |
| 기존 대출 연 원리금 | number | 원 (DSR 계산용) |
| 기존 대출 연 이자 | number | 원 (DTI 계산용) |
| 담보 가치(주택가격) | number + 단위버튼 | 원 |
| 지역 | radio | 규제지역 / 그 밖의 수도권 / 지방 (기본 규제지역) |
| 주택 보유 상태 | radio | 무주택·처분조건부 1주택 / 생애최초 구입 |
| 금리 유형 | radio | 변동형 / 혼합형(5년 고정) / 주기형(5년) / 고정형 |
| 신규 대출 연이자율 (%) | number | 약정금리 |
| 신규 대출 기간(년) | select | 10·20·30·40, 기본 30 (수도권·규제지역은 30년으로 잘라 계산) |
| 스트레스 DSR 적용 | checkbox | 기본 체크 (지역·금리 유형별 가산) |
| 상환 방식 | radio | 원리금균등 / 원금균등 / 만기일시 |

## 5. 결과 출력

| 항목 | 설명 |
|---|---|
| DSR 기준 한도 | 약정금리 + 스트레스 가산 금리로 역산 |
| LTV 기준 한도 | 담보가치 × LTV 비율 (정수 퍼센트 계산) |
| DTI 기준 한도 | 약정금리로 역산 |
| 주담대 최대한도 | 수도권·규제지역 6억·4억·2억, 지방 생애최초 6억, 그 밖 없음 |
| **최종 한도** | 위 기준과 담보가치 중 **최솟값**, 결정 요인(DSR/LTV/DTI/CAP) 표시 |
| 월 예상 상환액 | 최종 한도 × 약정금리 기준 |
| 한도 계산 금리 | 약정금리 + 가산(%p) |
